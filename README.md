# Shubham Dixit — academic website

Personal academic website for hydrology, hydroclimatic extremes and climate-informed risk.

## Website

https://hysunburg2407.github.io/

GitHub Pages publishes the main branch from the repository root. The deployment status is shown under Actions or Settings → Pages.

## Editing

The website is in `index.html`. Its CSS, JavaScript, portrait and decorative landscape are embedded. There are no packages to install and no build step.

- Search for section IDs `about`, `research`, `publications`, `teaching`, `activities`, or `contact` to edit content.
- Each `class="publication"` article has a `data-type` and `data-year` used by the filters. Values for type are `journal`, `review`, and `chapter`; `undated` is used where a publication year has not been assigned.
- `CV_Shubham_Dixit.pdf` is the current owner-supplied CV, linked from About, Publications and Contact. Replace this file when updating the download.
- Styles are in the `<style>` elements; interactions are in the `<script>` element near the end.
- `.nojekyll` tells GitHub Pages to serve the static files directly.
